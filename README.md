# 🛍️ Django E-Commerce Platform

A modern and responsive e-commerce web application built with **Django**, **Django REST Framework (DRF)**, **Tailwind CSS**, and **JavaScript**.  

This project delivers a full shopping experience with the following core features:
- User authentication and profile management
- Product browsing and category filtering
- A custom admin dashboard (without using Django’s default admin panel)
- AJAX-based favorite system powered by DRF

The frontend is built with Django templates, styled using Tailwind CSS, and includes dynamic interactions via the Fetch API.


---

## 🚀 Features

-  User Authentication (Register, Login, Logout)  
-  Custom Admin Dashboard for Product & Category Management   
-  Edit Profile (First Name, Last Name, Profile Picture)  
-  Browse and Filter Products by:
    -  Browse Products by Categories  
    -  Sort Products 
    -  Search Products by Name 
    -  Limit Number of Products per Page  
    -  Pagination  
-  Add/Remove Products to/from Favorites (AJAX & DRF)  
-  Custom User Model with Profile Picture and Favorite Products
-  Fully Responsive Design with Tailwind CSS  
-  Secure CSRF-Protected API Endpoints  

---

## 🛠️ Tech Stack

- **Backend:** Django, Django REST Framework  
- **Frontend:** HTML, Django templates, Tailwind CSS, JavaScript (Fetch API)  
- **Database:** PostgreSQL  
- **Media:** Django `ImageField`  
- **Authentication:** Django's built-in auth system
